# 工具适配与交接

本文件提供作者环境的工具调用示例。工具当前 schema、平台限制与用户授权优先；不同版本、主机和账号的能力可能不同。示例不是通用 API 契约。

## 模型与推理参数适配

`gpt-6-luna`、`gpt-6.1-sol`、`gpt-6-astra` 及其推理强度是作者环境的配置示例，不保证普遍可用，也不作为官方性能定位或价格依据。

首次使用或环境变化时，先检查当前工具 schema 和可用模型清单，再将主文件的 L、S、A、U 档映射到可请求的模型和强度。以当前费用或平台计量核对成本顺序；没有依据时记录成本未知。保留最低合格档优先、失败证据升级和五轮总上限，不能把模型不可用算成能力失败。

通过真实参数请求模型和强度，记录有效配置回显；没有回显则写“已请求，未回显”。提示词里写模型名不等于实际切换。若环境无法支持某档的对应能力或无法控制配置，报告限制，不能声称路由已生效。用户锁定模型或预算时，映射仍受其约束。

## 当前任务内的子代理

若当前环境提供 `collaboration.spawn_agent`，并支持 `model`、`reasoning_effort` 与 `fork_turns`，可参考以下示例；先检查当前 schema 是否允许这些字段和组合。作者环境的模型覆盖使用 `fork_turns: "none"`，全历史 fork 继承父模型且不能同时指定覆盖参数。

```json
{
  "task_name": "bounded_worker",
  "model": "gpt-6-luna",
  "reasoning_effort": "high",
  "fork_turns": "none",
  "message": "role: worker。此处填入完整任务卡、项目工作目录、适用规则入口、验收方式和返回要求。"
}
```

无历史 fork 不会自动拥有当前对话的决策。实际派发必须补全必要约束及读取入口，避免复制全部闲聊。先核对自定义 agent 配置是否覆盖请求值。

`followup_task` / `send_message` 若没有模型参数，就不能用于真实换模型。同模型返修可复用原代理；换模型需要原代理停写或完成后，以新参数派出接替者，传递原工作目录、变更和失败证据。保持同一修改范围只有一个写入者；短时间受阻不等于必须中断。

## 已有独立 Codex 对话

仅在用户已授权操作该执行对话、且当前工具支持时，使用 `send_message_to_thread` 发下一轮指令；若 schema 支持模型覆盖，显式传入 `model` 与 `thinking`。检查省略字段是否保留配置，记录实际工具行为，不承诺正在运行的推理即时换模。

先核对任务 ID、项目、工作目录与运行状态。若需换模型但无法安全排队后续轮次，先等待当前轮结束。其他对话类型可能不支持相同覆盖，先检查 schema。

## 新建独立对话

用户明确要求新建独立任务时才用 `create_thread`。按当前工具要求列项目并选择目标；仅用户明确指定该新聊天的模型时设置 `model`，否则省略并沿用用户默认配置，`thinking` 按用户要求和当前 schema 设置。独立新聊天不机械套用内部 worker 的显式选模要求，记录配置控制的限制即可。

默认使用 local；仅用户明确要求 worktree 且项目为 Git 仓库、工具支持时使用 worktree。若返回 `clientThreadId` 等准备中标识，等待就绪后再以真实 `threadId` 派后续指令。

本 skill 的默认子代理派工不等于用户要求创建侧栏任务。普通内部拆分使用子代理路径。创建接口不支持模型覆盖时，明确说明限制。

## 配置失败与可用性

参数被拒绝、模型不可用或权限不足时记录错误，不默默落到父模型。先修正参数或处理权限；确认为模型不可用时，可在政策允许的映射中选择最低合格且可用者，注明“可用性回退”，它不算便宜模型能力失败。用户锁定模型或给定预算上限时不能擅自改用更贵模型。无法控制或核实请求设置时，报告局限。

## 最小交接

```text
task_id / role: worker
目标与验收：
项目、工作目录和适用规则入口：
输入与已经确认的决策：
允许修改的范围、必须保留的约束：
依赖与可用工具：
请求模型/强度及选档理由：
已接受成果与证据、允许继续修改的部分、失败证据：
执行历史与已用同档修复次数、交接返工或阻塞：
长任务的检查点/停止条件、用户已有预算（如有）：
产物和验证结果的返回位置：
返回 PASS / CAPABILITY_FAILURE / BLOCKED，并附证据和未验证项。
```

模型字段仅是任务卡记录，必须同步设置真实工具参数。简短任务可用一段话表达同样信息，不强制填表。
